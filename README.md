# acervo_infindo_TRAB
 Esse acervo é uma fenda dimensional onde tudo e qualquer coisa que foi perdida pode ( ou não ) estar lá e, e criaturas ou pessoas vão e deixam qualquer coisa ou objeto lá. O sistema visa catalogar esses objetos e dar ao cliente a liberdade de criar um novo catálogo para itens novos.
